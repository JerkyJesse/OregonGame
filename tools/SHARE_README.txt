Get The Mech Outta Dodge
Windows 64-bit  (version 0.2.1)

How to play
1. Unzip this folder.
2. Run GetTheMechOuttaDodge.exe
   (one file — no .pck sidecar)

If Windows SmartScreen says "Windows protected your PC"
That is normal for a small unsigned game download. Click More info, then Run anyway.
Do not turn off antivirus.

Controls
WASD move, mouse look, E interact, F board, G hold hotwire, LMB fire.
